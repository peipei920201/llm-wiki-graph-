# 意願人篇 大綱

### P1 封面
- 訊息: 陪家人好好吃一餐，細心手工餵食的小重點
- 版型: cover
- 主張: C30
- 圖: 無

### P2 一餐的流程一眼看
- 訊息: 一餐可以分成餵前、餵中、餵後來準備
- 版型: figure
- 主張: C03, C05, C06, C07, C11, C10, C14, C32
- 圖: 流程圖｜清醒時進食→口腔清潔潤濕→坐直→一小口→吞嚥→確認口中沒有食物→餵後抬高；圖下註明「順序為整理，不是固定規定」
- 圖依據: C03, C05, C06, C07, C11, C10, C14, C32
- 互動: 小事｜對照自己的一餐，看看少了哪一步

### P3 先把環境準備好
- 訊息: 讓他在舒服、想吃的狀態下進食
- 版型: list
- 主張: C01, C02, C03, C05
- 圖: 無
- 互動: 想一想｜他平常最喜歡在哪裡、和誰一起吃飯？

### P4 坐好，一小口一小口餵
- 訊息: 姿勢、專注與每口的量，是安全進食的關鍵
- 版型: list
- 主張: C06, C31, C04, C07, C11
- 圖: 無
- 互動: 小事｜下一餐前先把姿勢調整好再開始

### P5 食物怎麼準備
- 訊息: 食物盡量均質，依吞嚥狀況選半流質或全流質
- 版型: figure
- 主張: C08, C15, C16, C09, C13, C23
- 圖: 對比圖｜半流質（像鹹粥、有顆粒）與全流質（像濃湯、很細緻），箭頭標示適合吞嚥較佳到稍差
- 圖依據: C15, C16
- 互動: 找人｜營養怎麼配、增稠劑怎麼用，請問營養師

### P6 留心觀察，吃完也要照顧
- 訊息: 不急不勉強，觀察小訊號，餵後抬高床頭
- 版型: list
- 主張: C10, C12, C14
- 圖: 無
- 互動: 想一想｜吃飯時，我有沒有注意到他的小訊號？

- 版型: list
- 主張: C23, C30
- 圖: 無
- 互動: 找人｜營養門診時段找營養師
